# Compass Mobile Healthcare Consulting — Website

One-page website for Compass Mobile Healthcare Consulting (CMHC),
deployed to Vercel at https://www.compassmobilehealthcare.com/.

## Files

- `index.html` — the homepage
- `services.html` — "How We Engage" page: the MIH Demand-Side Assessment ($9,950 fixed fee, 3 weeks)
- `styles.css` — shared stylesheet for both pages
- `cmhc-logo.png` — CMHC compass emblem
- `robots.txt` — allows all crawling, points to the sitemap
- `sitemap.xml` — the site's sitemap for Google Search Console

## Deploy

This repo is connected to the `cmhc-site` project in Vercel.
Pushing to this repo automatically redeploys the production site.
